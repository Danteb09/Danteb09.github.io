Using VIM to Make a Website

Learn how to open VIM, move around in it, and have text put onto a website!

Opening VIM

To open VIM, simply type vim [filename] into your terminal, assuming you are in the directory that holds your file.

Modes

Here are some modes that will get you started on VIM; there are many more modes available, beyond these.

  • On entry, you are in NORMAL mode, where you use h, j, k, and l to move left, down, up, and right, respectively.
    You can move using the arrow keys, as well. To return to NORMAL mode from any other mode, press esc.
  • Press i to enter INSERT mode. Within insert mode, you can type, delete, and copy and paste text as if you
    were editing a document (because you are).
  • Press shift + ; or : to enter Command-Line mode. The command line lets you save your work with w, quit with
    q, or even do both with wq, after you press return. There are many more commands as well, such as syntax on,
    which turns on colored syntax.
  • Press v to enter VISUAL mode by character, shift + v or V to enter it linewise, or ctrl + v to enter it blockwise.

Bare-Bones HTML

This is the minimum HTML page. You can copy and paste it into a .html document using VIM:

<!DOCTYPE html>
<html lang="en">
<head>
<title>This is the website's title</title>
</head>
<body>
<p>This is where the website text goes</p>
</body>
</html>

Adding Basic Text

By using a <p> element, you can write some paragraph text for your website.

  1. Type <p> between <body> and </body>
  2. Write what you want to write!
    • Use <br> to put text into a new line; html doesn't care about the line breaks in VIM.
  3. Finish your element with an endtag, </p> .

Now you know how to use VIM to write simple text onto a website!
